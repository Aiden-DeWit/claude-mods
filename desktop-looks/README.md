# desktop-looks

A Claude Code mod that gives the Claude desktop app a new look each time you open it. Each look changes the app's colors and draws art behind the conversation, kept to the corners and edges so the chat stays easy to read. Every look has a light and a dark version that follows your app's mode.

## The looks

Deep Space, Modern Minimal, Botanical, Coastal, Zen Garden, Nordic, Art Deco, Bauhaus, Synthwave, Night Sky, Desert, Stationery, Watercolor and Blueprint.

Deep Space has a slowly turning spiral galaxy, twinkling stars and shooting stars that cross different corners at different times. Night Sky has twinkling stars. Botanical leaves sway, Coastal waves roll, and a few others drift slowly. If you have reduced motion turned on, the art stays still.

## Commands

- `/look` lists the looks and shows which one is on.
- `/look next` switches to the next look now.
- `/look <name>` pins one look, for example `/look deep space`. Every session uses it until you cycle again.
- `/look cycle` goes back to a new look each session.

## Where it shows

The desktop and mobile apps draw the looks. The terminal and editor extensions do not.
