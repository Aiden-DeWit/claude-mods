# claude-mods

Where all my Claude Code mods are stored.

## Install

In Claude Code, add this repository as a marketplace, then install a mod from it:

```
/plugin marketplace add Aiden-DeWit/claude-mods
/plugin install desktop-looks@aiden-dewit-mods
```

## Mods

| Mod | What it does |
| --- | --- |
| [desktop-looks](desktop-looks/) | A new art-style look for the Claude desktop app each time you open it: colors plus background art, in light and dark. |
